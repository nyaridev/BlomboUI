The plan in one screen

Full reasoning is in docs/architecture.md and docs/adr/ in BlomboUI-new.

One language ADR-0001

The server moves from Python/FastAPI to TypeScript on Node. One Zod schema per shape, shared by client and server. Python stays inside ComfyUI only.

Node 22+HonoZodnode:sqlitesharp

Web + desktop ADR-0002

One local server. start-web.bat opens your browser. start-app.bat opens a Tauri window on the same UI.

Tauri 2:4380

Workflow packages ADR-0003

Any ComfyUI graph plus a manifest that binds UI to inputs. Drag and drop to import. Presets use the same format. Templates are gone.

rolesanalyzer.blombo export

Stages ADR-0004

Hires fix, ADetailer and ControlNet are graph patches that attach to role ports, so they work on imported workflows too.

Layout documents ADR-0005

The Generate screen is data. The default keeps the familiar arrangement. Customize mode moves blocks and switches control styles. Layouts save as presets.

dnd-kitpresets

Profiles as folders ADR-0006

Profile screen on launch, creation wizard, hot switching. Settings, workflows and layouts are JSON files. SQLite holds only indexes.

Own design system ADR-0007

Hand-built controls on tokens, Floating UI for behavior, Motion springs, a custom SVG icon set. No shadcn look.

React 19Tailwind 4MotionFloating UI

Live bus ADR-0008

One WebSocket for progress, previews, VRAM and temperature, downloads and errors. No more polling every 2–4 seconds.

ComfyUI bridge ADR-0009

A bundled ComfyUI extension: "Edit in ComfyUI" opens the graph, and "Save to Blombo" writes it back.

Roadmap

Phases build on each other. Each phase ends with something you can open and use.

Phase 0

Foundation and style review

Design system, icons, Design Lab, preview screens, app shell, profile screen, launchers, Tauri window, docs and agent rules.

Phase 1

Generate core

ComfyUI supervisor, live bus, workflow packages, analyzer, presets, compiler, default Generate layout, prompts and autocomplete, loaded-models strip, image stage.

Phase 2

Library

Gallery showcase, File Info, local models and the unified model card, Wildcard Manager.

Phase 3

Online

Civitai browser, model pages, download queue, ComfyUI Manager store.

Phase 4

Power features

Hires, ADetailer and ControlNet stages, Customize mode, layout presets, ComfyUI bridge, scripts, batch utilities.

Phase 5

Polish

Settings overview stats, Help and prompt guide, Scopes, command palette, notifications.
